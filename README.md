# M-Pesa Smart Budgeting Assistant — UX Case Study

A full UX case study exploring the design of a native AI-powered budgeting feature for M-Pesa, Kenya's dominant mobile money platform serving 32M+ daily users.

---

## Overview

M-Pesa processes billions of shillings daily, yet offers users no meaningful view of where their money goes. This case study designs a **Smart Budgeting Assistant** — a contextual AI layer built directly into the M-Pesa app — that uses real transaction data to automatically categorise spending, surface insights, and offer proactive financial guidance in Swahili and English.

## Key Features Designed

1. **Auto-Categorisation Engine** — Tags every transaction using till numbers, paybill codes, and recipient patterns. No user input required.
2. **Payday Budget Planner** — Salary-triggered flow that pre-fills a budget from last month's spending in under 60 seconds.
3. **Conversational AI Coach** — Natural language Q&A ("Nimetumia pesa ngapi kwa chakula?") powered by live transaction data.
4. **Smart Spending Nudges** — Proactive alerts that fire at the right moment — 75% category threshold, unusual transactions, savings deadlines.
5. **Business / Personal Split Mode** — Auto-tagging for SME users with a separate business dashboard exportable for SACCO or KRA use.
6. **Household & Chama Shared View** — Co-managed budgets for couples and a treasurer mode for savings groups with shared contribution ledgers.
